# some instructions!
## for `bash` and `shell`
create symlinks so this can work
* `ln -s ~/.config/bash/config.bash .~/bashrc`
* `ln -s ~/.config/bash/profile.bash ~/.bash_profile`
* `ln -s ~/.config/shell/profile.sh ~/.profile`


then change the default shell -> `chsh -s /usr/bin/bash`
